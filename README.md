# Менеджер Бібліотеки Книг

Практичне завдання №2 з JavaScript: змінні, функції, масиви, об'єкти.

## Опис

Консольна програма для управління бібліотекою книг. Бібліотека зберігається як масив об'єктів. Кожна книга має властивості:

- `title` — назва (рядок)
- `author` — автор (рядок)
- `year` — рік видання (число)
- `genre` — жанр (рядок)
- `available` — статус доступності (`true` / `false`)

## Функціонал

| Функція | Опис |
|---------|------|
| `addBook(library, newBook)` | Додає нову книгу |
| `removeBook(library, title)` | Видаляє книгу за назвою |
| `findBooksByAuthor(library, author)` | Шукає книги за автором |
| `getTotalBooks(library)` | Повертає загальну кількість книг |
| `toggleAvailability(library, title)` | Змінює статус (доступна ↔ видана) |

## Як запустити

### Варіант 1 — Node.js

```bash
node library-manager.js
```

### Варіант 2 — Браузер

1. Відкрий консоль розробника (F12 → Console)
2. Скопіюй вміст файлу `library-manager.js` і встав у консоль
3. Натисни Enter

## Технології

- Чистий JavaScript (ES6+)
- Без DOM і зовнішніх бібліотек
- Використано: `let` / `const`, звичайні та стрілкові функції, методи масивів (`push`, `splice`, `filter`, `find`, `findIndex`, `forEach`)
